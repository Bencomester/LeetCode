This repository contains my personal solutions to algorithmic and database problems from [LeetCode](https://leetcode.com/). The solutions demonstrate data structure manipulation, algorithm optimization, and database querying across multiple programming languages.

## Repository Structure

To keep the repository organized, solutions are categorized by programming language. The C++ solutions are further grouped into batches of 500 to handle the large volume of files. Each file is named according to its corresponding LeetCode problem number (e.g., `0001.cs`, `0175.sql`, `2620.js`).

```text
LeetCode/
├── cpp/
│   ├── 0001-0500/    # C++ solutions (Problems 1-500)
│   ├── 0501-1000/    # C++ solutions (Problems 501-1000)
│   └── ...
├── csharp/           # C# solutions
├── javascript/       # JS solutions (Including 30 Days of JS challenges)
├── sql/              # SQL queries (Database problems)
├── java/             # Java solutions
├── bash/             # Shell scripting challenges
└── README.md
```

## Languages & Focus Areas

* **C++ / C# / Java:** Primarily used for complex algorithmic challenges requiring optimal time and space complexity (e.g., dynamic programming, graph traversals, tree manipulation).
* **JavaScript:** Used for algorithmic problems and specific frontend/closure-based challenges.
* **SQL:** Used exclusively for database querying challenges, focusing on aggregations, joins, and window functions.
* **Bash:** Used for shell scripting and text processing problems.

## How to Navigate

You can search for a specific problem by its number using GitHub's file search (`t` shortcut). The file names are zero-padded to four digits (e.g., Problem 1 is `0001.cs`) to ensure proper numerical sorting within directories.
